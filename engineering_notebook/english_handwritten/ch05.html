5.2 Mechanical Assembly: Chassis System

Subsystem Description: Dual-motor differential drive chassis.

Transmission: Using 48T:24T gears for a 1:2 speed ratio. This design ensures the robot can cover the field quickly.

Engineering Challenge: High-speed gears require high structural rigidity. Early tests showed the chassis risked deforming under high torque.

Solution: Added an "H" type reinforcement beam structure in the middle and extra bearing supports for the gear shafts, significantly improving rigidity.


5.3 Mechanical Assembly: Lift Arm & Pneumatic Claw

Lift Mechanism: Built a single-sided four-bar linkage. To lower motor load, we added a rubber band gravity compensation system. Tests show the motor needs very little current to hover.

Pneumatic Claw:

  • Actuators: Installed two single-acting cylinders.
  • Air Circuit: Tank -> Switch -> Regulator -> Solenoid -> Cylinder.
  • End Treatment: Added rubber pads to the inner claw to stop slippery Pins from falling out.

5.4 System Integration & Wiring

With subsystems complete, we integrated everything, focusing on wiring and air tube placement.

Cable Management

To keep wires away from moving parts, we:

  • Zoned the Wiring: Put power/signal lines and air tubes on opposite sides of the arm to prevent tangling.
  • Handled the Flip Joint: For the 180-degree wrist, we used a spiral wrap for the air tubes to allow for extension without stress.
  • Secured Everything: Used nylon zip ties along the beams to keep the robot neat and easy to maintain.

5.6 Remote Control Logic (Teleop)

To help the driver react quickly, we set up the following controller logic:

Module Button Description
Chassis Movement Joysticks (A/B/C/D) Tank Drive mode: Left and right sticks control each side independently.
Pneumatic Claw R Up / R Down R1 to Close (Grab), R2 to Open (Release). Instant response for fast grabbing.
Flip Wrist L Down Single button toggle. Press to flip to 180°, press again to reset to 0°.

5.7 Sensor Integration & Automation Testing

To improve environmental awareness and autonomous performance, we added these sensors:

Distance Sensor

Front-mounted. Used for "proximity detection": if an object is closer than 100mm, it auto-brakes to prevent collisions.

Autonomous Testing

Wrote a basic routine: Move forward -> Gyro correction -> Distance sensor stop -> Release claw -> Back up. 90% success rate!
